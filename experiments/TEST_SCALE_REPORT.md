## I. Stability interpretation

**Measured:** in B the official macro F0.5 drops from 0.962847 to 0.840024. Recall is almost unchanged (93.14% vs 94.08%); precision
collapses (82.45% vs 98.22%), mainly through false merges (302,910 FPs vs 26,047; singleton false-merge rate 57.47% vs 8.07%).

**Where the false positives come from** (`experiments/test_scale/stress/orphan_decomposition.json`):
- 272,558 of the 302,910 FPs (90.0%) are on **fit-fold records**. 0 of them are true matches.
- These records are true targets of fit-fold S1 entities that are **not queried** in B ("orphaned targets"). Their real owner never
  competes, so some validation S1 becomes the best S1 for the target (`t_rank` = 0) by default. The model relies heavily on that
  signal (76.5% of GBDT gain).
- B has 0.043 S1 per pool record, against 0.214 in validation and 0.174 on the real test set. So B is far more "orphaned" than test.
  The target-competition features shift *majorly* in B (PSI: `t_gap` 1.18, `t_ncand` 0.92, `t_rank` 0.56). On the actual test
  set (`experiments/test_scale/TEST_SCALE_REPORT.md`) the same features shifted *negligibly* (PSI 0.07, 0.07, 0.03).
- Diagnostic decomposition, not a configuration: restricting the same measured predictions to validation-pool records gives
  macro F0.5 **0.95603** (pair P 97.91%, R 93.14%, singleton false-merge rate 11.67%). The larger candidate environment by itself
  (+24% candidates, more same-name candidates) costs about 0.007 F0.5. Orphaned targets account for the rest of the drop.

**Conclusion:**
- The matcher is **stable when every target's owner S1 is among the queries**, as it is in the real test set, where all test S1
  are queried.
- It is **not robust to targets whose owner S1 is absent**. On such records its reliance on `t_rank` produces confident false
  merges, especially near-duplicate records that differ only in legal form ("Rocky Learning Center" vs "… CORP.").
- The test pool has 5.75 S2+S3 records per S1, against 4.68 in train. Whether those extra records behave like orphaned targets
  (near-duplicates of businesses with no test S1) is unknown without labels, so this remains a real risk.

## J–K. Integrity

- **Limitations:**
  - B does not reproduce the test S1-to-pool ratio (0.043 vs 0.174). It is a pessimistic environment for target-competition

  - No labelled environment matches the test ratio *and* test pool size at once.
